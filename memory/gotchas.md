# Gotchas (git-tracked, shared)

Known issues, things that did not work, and surprises. One line per entry.

Format: `[YYYY-MM-DD] Gotcha: <what happened> — Fix: <what worked>`

<!-- Entries below -->
[2026-08-13] Gotcha: Scryfall's CDN returns 400 "Your User-Agent header is currently set to default or generic value" to Next's server-side image optimizer, so every next/image card thumbnail breaks under `next dev`. remotePatterns was never the problem. Vercel's optimizer sends an accepted UA so production is fine — Fix: `images.unoptimized: process.env.NODE_ENV === "development"` in next.config.ts. Note `next start` locally still breaks (NODE_ENV=production).
[2026-08-13] Gotcha: the typecheck commit-gate hook ran `npx tsc --noEmit` at the repo root, but there is no root tsconfig.json — tsc printed its help banner and exited 0, so every commit passed the gate regardless of type errors. Silently fail-open since init — Fix: hooks now run `pnpm typecheck` / `pnpm lint`; verified exit 2 on a planted type error.
[2026-08-13] Gotcha: cc-rig generates `.mcp.json` pointing at `@anthropic/mcp-playwright`, which does not exist on npm (404) — the Playwright MCP has never worked in any cc-rig project here, incl. GreatBanquet-Site — Fix: empty the repo-level mcpServers and let the `playwright` plugin supply `npx @playwright/mcp@latest`.
[2026-08-13] Gotcha: Node Playwright and Python Playwright pin different chromium revisions (1234 vs 1223). Installing browsers for one leaves the other failing with "please run playwright install" — Fix: run both `npx playwright install chromium` and `python3 -m playwright install chromium`.
[2026-08-13] Gotcha: hardening SECURITY DEFINER functions with `search_path = public` alone breaks card search — pg_trgm and uuid-ossp live in Supabase's `extensions` schema, so the trgm operators fall out of scope — Fix: pin to `public, extensions, pg_temp` (see migration 016).
[2026-08-13] Gotcha: the first Supabase query after the project sits idle can fail with "canceling statement due to statement timeout" — cold start, not a broken query or RLS problem — Fix: just retry; subsequent calls settle to ~500ms.
[2026-08-13] Gotcha: `vercel link` writes `.vercel/project.json` into the *current* directory. Running it from `~` silently links your home folder and the repo still reports unlinked — Fix: run it from the repo root, or move the stray `~/.vercel` in. CLI auth lives separately in `~/Library/Application Support/com.vercel.cli`, so moving the folder is safe.
[2026-08-13] Gotcha: `cards_name_trgm_idx` is a GIN trigram index — it serves fuzzy `%` matching, NOT equality. There was no index on `lower(name)` at all, so every exact-name lookup seq-scanned ~114k rows. Deck import died on it: 470ms warm, 5,449ms cold, past the statement_timeout Supabase pins per role (anon 3s, authenticated 8s) — Fix: migration 017 adds `cards(lower(name))` + a partial index on the DFC front face. 20ms warm after.
[2026-08-13] Gotcha: `col = ANY(SELECT lower(unnest(p_arr)))` plans as a hashed SubPlan filter over a seq scan and can NEVER drive an index scan, no matter what indexes exist. Same for OR-ing two different expressions in one WHERE — the planner can use at most one index and in practice uses neither — Fix: make the array a CTE that drives a nested-loop join, and UNION ALL the branches instead of OR-ing them (see migration 017).
[2026-08-13] Gotcha: Supabase does not grant permission for `ALTER FUNCTION ... SET pg_trgm.similarity_threshold` (42501). pg_trgm's `set_limit()` works fine from `authenticated` though — Fix: call `set_limit()` inside a plpgsql function, capturing `show_limit()` first and restoring it before returning. PostgREST pools connections, so an unrestored value silently retunes every later `%` query on that connection.
[2026-08-13] Gotcha: a route that returns `[]` on a database error makes a failed query indistinguishable from "no rows matched". This is exactly how a 5s query timeout surfaced to the user as "88 cards not found" — Fix: return a non-200 with a message and let the UI say "lookup failed". Prefer this over silent degradation anywhere a caller renders the empty case as a real answer.
[2026-08-13] Gotcha: `supabase link` writes `supabase/.temp/` into the repo, including `pooler-url` which can carry connection credentials — Fix: it is now in .gitignore. Don't commit it.
